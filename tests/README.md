# Тесты сайта

Тесты открывают сайт в настоящем браузере (Chromium через Playwright) и проверяют то,
что видит посетитель. Сайт для тестов поднимается сам, отдельный сервер запускать не нужно.

## Установка (один раз)

```bash
python3 -m venv .venv
.venv/bin/pip install -r tests/requirements.txt
.venv/bin/python -m playwright install chromium
```

## Проверка сайта (~2 минуты)

```bash
.venv/bin/pytest tests -q
```

Что проверяется:
- все страницы открываются на EN и UA без ошибок и битых картинок;
- меню: все пункты на месте, ведут куда нужно, текущая страница подсвечена;
- переключатель языка работает и запоминается при переходе по страницам;
- каталог показывает все картины, фильтр по художнику работает;
- каждая страница картины: название, главное фото, кнопка Enquire ведёт на почту;
- каждая страница художника: имя и все его работы;
- на телефоне (375 px) страницы не шире экрана;
- на страницах не видно цен;
- название сайта одно и то же везде (если задано `site_name` в `tools/seo.config.json`);
- доступность (axe): падает только на критичных ошибках; отчёт: `.venv/bin/pytest tests -k accessibility -s`.

## Сравнение внешнего вида «до / после»

```bash
.venv/bin/python tests/visual.py baseline   # перед изменениями
.venv/bin/python tests/visual.py compare    # после изменений
```

Различия сохраняются в `tests/screenshots/diff/` (изменённые места выделены красным).
